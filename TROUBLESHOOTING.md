# Troubleshooting / Решение проблем

**Не запускается сборка.** `java -version` и JAVA_HOME должны указывать на JDK 25. Wrapper требует сеть на первом запуске. Проверьте корпоративный proxy/Maven settings; не отключайте системную защиту. При ограничении записи Maven-кэша можно использовать `mvnw.cmd "-Dmaven.repo.local=.mvn/repository" verify`.

**Access denied в ограниченном окружении агента.** Песочница может запрещать rename/hardlink даже временных файлов. В фактическом тестировании они проверялись обычным процессом вне песочницы, без повышения прав самого приложения. Это не повод обходить ограничения пользователя или помечать тест успешно без повторного выполнения.

**Ошибка настроек.** Невалидный JSON/диапазон даёт явную ошибку запуска. Закройте приложение, сохраните копию `%LOCALAPPDATA%\Enro\settings.json` и переименуйте файл; следующий запуск создаст настройки по умолчанию. История в БД не теряется. Не импортируйте неизвестный JSON вслепую: он может изменить папку плановых анализов.

**Приложение уже запущено.** Одна папка данных обслуживается одним процессом. Закройте существующее окно. Файл instance.lock может остаться после сбоя; блокировку держит процесс, а не наличие файла, поэтому удалять его обычно не нужно.

**PARTIAL / LIMIT_REACHED / CANCELLED.** Это реальные неполные результаты. Проверьте счётчик ошибок, исключения и лимиты. Symlink/junction/reparse/cloud placeholders пропускаются. Нельзя сравнивать сумму логических файлов с физически занятым местом тома: квоты, hard links, sparse/compressed files, системные данные и ошибки чтения дают различия.

**Нет прогресса в процентах.** До окончания обхода общее число файлов неизвестно. Показатель намеренно неопределённый; рядом отображаются реальные счётчики. Хеширование крупных файлов может длиться долго. Используйте Отмену.

**Нет кандидатов очистки.** Поддерживаются только явные правила: верхний уровень пользовательской Temp старше 7 дней, ручной анализ Downloads или выбранные обычные файлы. Защищённые области исключаются. Программа не называет старые/большие файлы мусором.

**Файл изменился после проверки.** Повторите сканирование. Не обходите отказ переименованием, подменой пути или запуском от администратора.

**Не удалось переместить в Корзину.** Поддерживаются локальные fixed drives; файл может быть занят, защищён или недоступен. Windows может показать своё окно. Не подтверждайте постоянное удаление, если хотите восстановление. Enro не заменяет неудачную recycle-операцию вызовом delete.

**Не работает отмена перемещения.** Целевой файл должен существовать с прежним File ID, размером и временами; исходный путь должен быть свободен. Посмотрите оба пути в журнале. После изменения файла восстановите расположение вручную средствами Windows с самостоятельной проверкой конфликтов.

**Планировщик не сработал.** Приложение должно быть открыто. Следующий запуск обработает одно пропущенное задание; история покажет результат. Автоудаление отсутствует, а уведомления находятся в строке состояния.

**JavaFX unsupported configuration при ручном classpath-запуске.** Используйте Maven javafx:run или готовый EXE: релиз использует JavaFX как named modules во встроенном runtime.

**Установщик не собирается.** Проверьте JDK 25 jpackage и доступный ему WiX. Portable `-Type portable` не требует WiX. Не смешивайте x86 и x64. Данные пользователя не должны лежать в target/ или release/Enro, которые сборка пересоздаёт.

**Диагностика.** Настройки → Экспорт диагностики. Отчёт не содержит путей. Логи: `%LOCALAPPDATA%\Enro\logs`. Прежде чем делиться CSV, JSON или SQLite, проверьте содержащиеся в них личные пути.
