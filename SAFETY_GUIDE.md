# Модель безопасности

Enro работает с обычными правами пользователя и не повышает их. Сканирование и обнаружение кандидатов — операции чтения. Программа не отключает защиту Windows, не изменяет системные настройки, не устанавливает драйверы/службы и не выполняет очистку по таймеру.

## Перед очисткой

1. Сделайте резервную копию важных данных.
2. Просмотрите полные пути и причину. Размер, возраст, имя и расширение сами по себе не доказывают ненужность.
3. Выбирайте отдельные файлы. В этой версии все предлагаемые кандидаты MEDIUM; LOW не присваивается без подтверждённого правила производителя.
4. Проверьте способ: Windows Recycle Bin. Не считайте Корзину резервной копией и не считайте её немедленным освобождением места.
5. Подтвердите точный набор. Изменившиеся файлы требуют новой проверки.

## Запреты и границы

HIGH/UNKNOWN запрещены исполнителем. Заблокированы Windows, Program Files, ProgramData, AppData (кроме точного пользовательского Temp), WinSxS, Recovery, System Volume Information, `$Recycle.Bin`, `.ssh`, `.aws`, `.gnupg`, `.git` и собственные данные Enro. Пути нормализуются и сравниваются после разрешения коротких имён, чтобы `PROGRA~1` не обходил запрет. Проверяются все предки и Windows reparse attributes. Ссылки, junction и cloud reparse placeholders консервативно пропускаются. Системный диск можно анализировать без разрешения его очистки.

Путь должен находиться внутри явно разрешённой папки, а обычный файл должен совпадать с предпросмотром по Windows File ID/идентификатору файловой системы, размеру, mtime и creation time. На файловой системе без надёжной идентичности операции не предлагаются. Проверка mtime использует миллисекундную точность; это не защита от намеренной подмены данных с сохранением метаданных.

Recycle adapter использует IFileOperation, FOFX_RECYCLEONDELETE, ADDUNDORECORD, EARLYFAILURE и WANTNUKEWARNING; не вызывает Files.delete для пользовательской очистки. Поддерживаются локальные fixed drives. Windows может показать собственное подтверждение, если условия Корзины изменились. Не подтверждайте безвозвратное действие, если не желаете его. Приложение не реализует собственный постоянный delete fallback. Перемещение в Корзину подтверждено интеграционным тестом только на текущей Windows/NTFS; поведение при полной/отключённой Корзине требует дополнительной приёмки.

Проверка пути непосредственно перед Shell/NIO-операцией уменьшает окно гонки, но не устраняет его полностью. Приложение не является границей безопасности против другого вредоносного процесса с теми же правами: у Shell операция по имени, возможна подмена между проверкой и исполнением. Для hostile-namespace сценариев потребовалась бы отдельная реализация handle-relative staging и более широкие системные тесты. Не запускайте очистку в каталогах, одновременно управляемых недоверенным ПО.

Организатор использует same-volume rename без замены цели. Нет cross-volume copy+delete. Отмена проверяет идентичность, время и отсутствие файла по исходному имени. Отключение питания или ошибка диска может оставить INTERRUPTED-запись. Журнал не гарантирует восстановление при потере диска или данных самой SQLite.

## Приватность

Сеть для анализа не используется. SQLite хранит пути локально, логи — коды/счётчики без путей. Учетная запись, имеющая доступ к `%LOCALAPPDATA%\Enro`, может прочитать историю: отдельного шифрования нет, применяется Windows ACL текущего пользователя. Не размещайте каталог данных в общей сетевой папке. CSV/JSON exports могут содержать личные пути; диагностика исключает их. Enro не отправляет отчёты автоматически.
