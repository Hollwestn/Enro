# Установка Enro 2.0

Windows 10/11 x64. Файлы Enro-2.0.0.exe, Enro-2.0.0.msi и Enro-Portable-2.0.0-win-x64.zip доступны в [GitHub Releases](https://github.com/Hollwestn/Enro/releases/tag/v2.0.0). При локальной сборке они находятся в release/. В них включены Java 25 и JavaFX 25.0.2, отдельно устанавливать Java не требуется.

Запустите EXE/MSI и следуйте мастеру установки для текущего пользователя. Ярлык запускает Enro. Для portable распакуйте весь ZIP в доступную папку и запустите Enro/Enro.exe; оставьте runtime/ и app/ рядом. Portable использует стандартную папку данных пользователя, а не папку исполняемого файла. Службы, драйверы и автоматическая очистка не устанавливаются.

~~~powershell
Get-FileHash .\release\Enro-2.0.0.exe -Algorithm SHA256
~~~

Сравните результат с release/SHA256SUMS.txt. Локальные сборки не подписаны. Сборка установщика не равна проверке установки/удаления на чистой Windows; фактическое покрытие — в TEST_REPORT.md.

Данные: %LOCALAPPDATA%\Enro (settings.json, enro.db, instance.lock, logs/). Одновременно профиль открывает один экземпляр. Версия 2.0 использует отдельный профиль Enro; данные предыдущих сборок автоматически не переносятся и не удаляются. Удаление приложения не очищает эту историю, Корзину или перемещённые файлы.

Для сборки исходников требуются JDK 25 и Maven Wrapper; для EXE/MSI также WiX, поддерживаемый jpackage. Подробные команды — START_HERE.md.
