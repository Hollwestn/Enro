# Начните здесь — Enro 2.0

## 1. Получить проект

Скачайте Enro-Source-2.0.0.zip из [GitHub Releases](https://github.com/Hollwestn/Enro/releases/tag/v2.0.0) и распакуйте в обычную доступную папку, например C:\Projects\Enro. Не работайте внутри ZIP. Исходный архив содержит pom.xml, src/, docs/, scripts/ и Maven Wrapper. Готовое приложение можно установить сразу, пропустив шаги 2–5.

## 2. Установить JDK 25 для разработки

Установите JDK 25 x64 от выбранного поставщика (например, Oracle JDK или OpenJDK). Для запуска готового EXE/MSI/portable отдельная Java не нужна. В PowerShell укажите фактический путь:

~~~powershell
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-25.0.3'
& "$env:JAVA_HOME\bin\java.exe" -version
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
~~~

Ожидается версия 25.x. JRE без компилятора для сборки недостаточно.

## 3. Открыть проект

Откройте папку Enro или pom.xml в IntelliJ IDEA/другой Maven IDE. SDK проекта и Maven runner — JDK 25. Либо откройте PowerShell в папке, где находится pom.xml.

## 4. Собрать Maven Wrapper

~~~powershell
.\mvnw.cmd -B -ntp verify
~~~

Первый запуск загружает закреплённый Maven 3.9.16 и зависимости, поэтому нужен интернет. Ожидается BUILD SUCCESS, target/enro.jar и target/surefire-reports. Проверка symbolic link может быть пропущена без имеющегося права создания ссылки. Дополнительные native-тесты:

~~~powershell
.\mvnw.cmd -Denro.nativeTests=true verify
~~~

Эти тесты работают только с созданными ими файлами. Они проверяют junction/ACL/блокировку и реальную Корзину с восстановлением собственного QA-файла. Личные файлы для тестов не используются; настройки Windows не меняются.

## 5. Запустить исходники

~~~powershell
.\mvnw.cmd javafx:run
~~~

Ожидается окно Enro: постоянное боковое меню, светлая тема, реальные диски. При первом запуске история пуста.

## 6. Установить готовую сборку

Скачайте Enro-2.0.0.exe или Enro-2.0.0.msi из [GitHub Releases](https://github.com/Hollwestn/Enro/releases/tag/v2.0.0), запустите установщик и пройдите мастер установки для текущего пользователя. Ярлык запускает приложение. Portable: распакуйте весь Enro-Portable-2.0.0-win-x64.zip и запустите Enro/Enro.exe. Не извлекайте только EXE — рядом нужны app/ и runtime/.

Для собственного установщика нужны JDK 25 и WiX, поддерживаемый jpackage (в проверенном окружении WiX 3.11):

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\package-windows.ps1 -Type all
~~~

Ожидаются EXE, MSI, portable ZIP и SHA256SUMS.txt в release/. Параметр Bypass действует только для этого процесса PowerShell. Для portable без WiX используйте -Type portable.

## 7. Выбрать диск

В «Обзоре» нажмите «Проверить» у нужного диска. Для небольшой области нажмите «Выбрать папку». Карточка показывает ёмкость, занятое/доступное место и файловую систему из Windows.

## 8. Выполнить первое сканирование

Выберите небольшую папку с тестовыми копиями. Выбор через главное действие сразу запускает проверку. На странице «Файлы» можно изменить путь и нажать «Проверить». Внизу показываются число файлов, логический размер и пропуски. «Остановить» сохраняет частичный результат с соответствующим статусом. После завершения открывается список файлов.

## 9. Пользоваться картой

В «Файлах» откройте вкладку «Карта места». Наведение показывает путь и размер, щелчок выделяет запись, двойной щелчок открывает папку. «Назад» возвращает к родителю. «Показать в списке» переключает вкладку. Контекстное меню открывает расположение. Карта отображает текущую страницу до 350 непосредственных элементов; страницы и фильтры меняют её состав. Площадь означает логический размер, а не физическое выделение NTFS. Маленькие и пустые элементы смотрите в списке.

## 10. Найти дубликаты и крупные файлы

«Дубликаты» → «Найти дубликаты». Слева выберите группу, справа проверьте сохраняемый экземпляр и другие копии. Совпадение подтверждается содержимым, не именем. Сохраняемый экземпляр защищён от выбора. Другие копии можно передать в предпросмотр; удаление автоматически не запускается.

В «Крупных файлах» задайте минимум в МиБ, тип и число дней после изменения → «Применить». 0 дней означает любую дату, 0 МиБ — любой размер. Возраст не доказывает ненужность файла.

## 11. Безопасно очистить файлы

«Очистка» → «Проверить файлы» для Temp или Загрузок. Либо выделите обычные файлы в таблице → «Проверить выбранные…». В предпросмотре отметьте конкретные флажки; выбор изначально пуст. Читайте полный путь, причину, размер, категорию и риск. «Далее» открывает отдельное подтверждение с точным количеством и объёмом. Перед исполнением Enro ещё раз проверяет состояние каждого файла и пути. Защищённые/изменившиеся файлы отвергаются.

Поддерживается Корзина Windows. Перемещение в неё не гарантирует немедленно освободившееся место. Если назначение файла неясно, оставьте его.

## 12. Восстановить данные

Откройте «Историю». Для RECYCLE нажмите «Открыть Корзину» и восстановите файл средствами Windows, пока он там доступен. Для успешного перемещения MOVE выберите запись → «Отменить перемещение». Возврат возможен, если файл не изменён и прежнее имя свободно. После безвозвратного удаления вне приложения восстановление не обещается.

## 13. Настроить автоматизацию

«Расписание» → «Добавить расписание» → папка → каждый день или каждую неделю. Enro должен оставаться открыт. Пропущенная проверка запускается один раз при следующем старте. Выбранное задание можно приостановить/включить; история показана ниже. Автоматизация только анализирует. Проверка при запуске настраивается отдельно в Настройках.

## 14. Изменить оформление и язык

«Настройки» → Светлая/Тёмная и цвет акцента: Индиго, Мята, Серебро, Роза, Янтарь или Графит. Оформление применяется сразу без перезапуска. Язык переключается RU/EN сверху либо сохраняется с остальными настройками. Параметры сканирования и исключения применяются после «Сохранить настройки». Дополнительные параметры можно раскрыть ниже.

## 15. Удалить Enro

Закройте приложение. Windows → Параметры → Приложения → Enro → Удалить. Portable удаляется вместе с распакованной папкой. Данные %LOCALAPPDATA%\Enro сохраняются отдельно; их можно удалить вручную после закрытия Enro, если история больше не нужна. Это не очищает Корзину и не отменяет перемещения.
