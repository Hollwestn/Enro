# История версий

## 2.0.0 — 25 октября 2026

Первый публичный выпуск Enro на GitHub.

- Единый интерфейс с постоянной навигацией, светлой/тёмной темой, шестью акцентами и русским/английским языком.
- Обзор реальных дисков, фоновые проверки и сохранённые результаты SQLite.
- Список файлов и интерактивная карта Canvas с переходами по папкам и CSV-экспортом.
- Поиск крупных/старых файлов и многоэтапное сравнение дубликатов с защищённым сохраняемым экземпляром.
- Ручной предпросмотр очистки с повторной проверкой состояния и перемещением в Корзину Windows.
- Организация Загрузок, журнал операций и отмена неизменённых перемещений.
- Расписание только для анализа, сохраняемые настройки и локальная диагностика.
- Установщики EXE/MSI и portable для Windows x64 со встроенной Java 25.
- Документация, скриншоты, контрольные суммы и автоматическая Windows-сборка.

Локально: 49 тестов, 48 успешно, 1 skip; packaged self-check PASS. Сборки без цифровой подписи. Win10, clean-VM установка/удаление и крупные нагрузочные сценарии требуют дополнительной приёмки. [Фактический отчёт](TEST_REPORT.md) · [Ограничения](README.md#границы-текущей-версии).
